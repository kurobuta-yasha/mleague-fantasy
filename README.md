# Mリーグ チーム選択ゲーム 集計

14人の参加者がそれぞれMリーグから3チームを選び、今レギュラーシーズン（2026-27）の
3チーム合計ポイントで順位を競うゲームの集計ツール。

## ルール（ざっくり）

- 参加者: 14人
- 各参加者がMリーグのチームを3つ選ぶ
- スコア = 選んだ3チームのレギュラーシーズン累計ポイントの合計
- 合計が多い人が勝ち

## ディレクトリ

- `data/` — 参加者の選択チーム、チーム成績などのデータ
- `docs/` — ルール詳細・仕様・メモ
